# Housing Data Analysis and Statistical Exploration

A Python-based data analysis project focused on exploring housing data using statistical methods, data visualization and exploratory data analysis (EDA).

## Overview
This project investigates housing data to identify patterns, understand distributions, analyze relationships between variables and explore statistical characteristics of the dataset.

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## Analysis Performed
- Exploratory Data Analysis (EDA)
- Descriptive statistics: mean, median, variance and standard deviation
- Data visualization and distribution analysis
- Correlation analysis
- Outlier detection
- Sampling techniques
- Confidence interval estimation
